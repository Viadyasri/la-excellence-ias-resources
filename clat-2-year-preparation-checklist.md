# CLAT 2-Year Preparation Checklist for Intermediate Students

A practical checklist for students preparing for CLAT alongside Intermediate studies.

The purpose of this resource is to help students track their progress across the major CLAT areas without turning preparation into an overwhelming daily routine.

---

## 🎯 CLAT Preparation Areas

* [ ] English Language
* [ ] Current Affairs & General Knowledge
* [ ] Legal Reasoning
* [ ] Logical Reasoning
* [ ] Quantitative Techniques

---

# 📅 Year 1 — Foundation Building

## Months 1–3

### English

* [ ] Develop a regular reading habit
* [ ] Practise comprehension passages
* [ ] Identify main ideas and arguments
* [ ] Improve vocabulary through context

### Logical Reasoning

* [ ] Understand basic reasoning concepts
* [ ] Identify premises and conclusions
* [ ] Practise short reasoning sets

### Legal Reasoning

* [ ] Understand the CLAT question format
* [ ] Practise principle-based questions
* [ ] Focus on applying information from passages

### Quantitative Techniques

* [ ] Revise basic mathematics
* [ ] Practise percentages
* [ ] Practise ratios and proportions
* [ ] Revise averages
* [ ] Strengthen basic algebra

### Current Affairs

* [ ] Select a manageable current-affairs source
* [ ] Develop a regular reading routine
* [ ] Start maintaining concise notes

---

# 📚 Months 4–6

* [ ] Increase reading-comprehension practice
* [ ] Practise longer reasoning passages
* [ ] Solve more legal reasoning sets
* [ ] Continue quantitative practice
* [ ] Revise current affairs weekly
* [ ] Attempt basic sectional tests
* [ ] Start maintaining a mistake log

---

# 🧠 Months 7–12 — Skill Development

## Practice

* [ ] Complete regular section-wise practice
* [ ] Increase passage-based questions
* [ ] Practise mixed question sets
* [ ] Revise weak topics
* [ ] Attempt sectional tests
* [ ] Begin occasional full-length mocks

## Mock Analysis

After every test, record:

| Problem       | Reason             | Action                  |
| ------------- | ------------------ | ----------------------- |
| Wrong answer  | Conceptual mistake | Revise concept          |
| Wrong answer  | Misread passage    | Improve reading         |
| Wrong answer  | Careless mistake   | Slow down               |
| Slow question | Time issue         | Practise timed sets     |
| Unattempted   | Ran out of time    | Improve time management |

# 🏆 Months 19–24 — Final Consolidation

### Revision

* [ ] Revise important concepts
* [ ] Revise current affairs
* [ ] Review mistake logs
* [ ] Revisit difficult topics

# 🎓 Balancing Intermediate + CLAT

Preparing for CLAT during Intermediate doesn't mean ignoring your academic studies.

A sustainable routine should include:

**Intermediate academics + CLAT preparation + revision + tests + adequate rest**

Students considering **CLAT Coaching for Intermediate Students** should check whether the program provides a realistic schedule rather than simply adding more study hours.

When comparing **CLAT Coaching with Intermediate in Hyderabad**, consider:

* [ ] Faculty experience
* [ ] Teaching methodology
* [ ] Study material
* [ ] Mock-test quality
* [ ] Performance analysis
* [ ] Mentoring
* [ ] Doubt-clearing support
* [ ] Schedule compatibility

An **Intermediate with CLAT Coaching** approach can be useful when both academic and entrance preparation are organized under a manageable plan.

---

# 🔄 Two-Year Progression

### Year 1

**Learn → Practise → Build skills → Identify weaknesses**

### Year 2

**Test → Analyse → Revise → Improve**

The objective isn't to complete everything as quickly as possible.

The objective is to become consistently better over two years.

---

# 🌱 Final Reminder

Starting early gives you time to develop the skills required for CLAT without relying entirely on last-minute preparation.

You don't need to be perfect in the beginning.

You need to keep improving.

**Read. Practise. Analyse. Revise. Repeat.**
